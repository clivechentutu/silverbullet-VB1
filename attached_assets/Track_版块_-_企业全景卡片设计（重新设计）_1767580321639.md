# Track 版块 - 企业全景卡片设计（重新设计）

## 📌 核心定位

在Track版块中为每个追踪对象新增一个**企业全景卡片区域**，类似企查查的企业详情页，展示该对象的**基本信息概览**。

**关键特点**：
- ✅ 静态内容为主（相对稳定，不频繁变化）
- ✅ 基于已有数据源（团队、融资、技术栈、媒体、招聘、营销）
- ✅ 面向中小企业和初创公司
- ✅ 简洁、易扫描的卡片设计
- ❌ 不包含合规认证、客户列表等难以获取的信息

---

## 🎨 Card设计细节

### Card的统一样式
```
┌─────────────────────────────────────┐
│ [Icon] Card标题        [更新时间]    │  <- 标题栏
├─────────────────────────────────────┤
│                                     │
│ 核心内容                            │
│ - 关键指标1                         │
│ - 关键指标2                         │
│ - 关键指标3                         │
│                                     │
├─────────────────────────────────────┤
│ [查看详情] [分享] [...]             │  <- 操作栏
└─────────────────────────────────────┘
```

### Card的交互
1. **点击Card** → 展开详细信息（可选）
2. **悬停** → 显示"更新时间"和"数据来源"
3. **右上角按钮** → 刷新数据、分享、更多操作
4. **内部链接** → 直接跳转到LinkedIn、Crunchbase等

## 💡 与现有系统的协同

### 与AI Insights的关系
- **企业全景** = 静态背景信息
- **AI Insights** = 动态信号分析
- 两者互补：用户先看全景了解背景，再看信号了解最新动态

### 与信号流的关系
- **企业全景** = "这个对象是谁"
- **信号流** = "这个对象最近在做什么"
- 信号流中的某些信号可以反映到企业全景中（如新融资、新高管等）

## 🎯 用户价值主张

这个**企业全景卡片**为用户提供：

1. **快速了解** - 一眼看到追踪对象的关键信息
2. **背景参考** - 理解信号的上下文（为什么这个信号重要）
3. **对标分析** - 快速对比多个竞争对手的基本面
4. **决策支持** - 基于全面的背景信息做出更好的决策
5. **时间节省** - 无需在多个平台间切换查找信息

---

## 📝 总结

**核心改变**：
- 从"10个全面的Card"精简到"8个实用的Card"
- 移除难以获取的信息（客户列表、合规认证等）
- 优先使用已有的数据源
- 专注于中小企业和初创公司的需求
- 静态内容为主，配合动态的AI Insights

**推荐MVP**：
从**基本信息、融资、团队、产品**这4个Card开始，然后根据用户反馈逐步扩展到8个Card。

这样既能快速上线，又能提供核心价值。
